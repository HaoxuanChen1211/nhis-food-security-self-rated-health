# Raw data

The raw National Health Interview Survey data are not included in this
repository.

To reproduce the analysis:

1. Visit the official [2024 NHIS data and documentation page](https://www.cdc.gov/nchs/nhis/documentation/2024-nhis.html).
2. Download the 2024 Sample Adult public-use CSV file.
3. Save the file in this directory as `adult24.csv`.
4. Run `analysis/reproduce_analysis.R` from the repository root.

The repository license applies to the original analysis code and
documentation, not to the NHIS source data.
